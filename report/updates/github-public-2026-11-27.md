# Bổ sung link GitHub và kiểm tra repo public

Ngày thực hiện: 27/11/2026. Theo phản hồi sinh viên, cô yêu cầu trong báo cáo
có link GitHub của project và repository phải công khai.

Repository: [TienMoi79/digits-rf-optimization](https://github.com/TienMoi79/digits-rf-optimization).
GitHub API xác nhận `visibility: public`, `private: false`. Truy cập HTTP
không gửi token/cookie trả về 200; không cần đổi quyền vì repo đã public.

[Bản Word cập nhật](../Bao_cao_Do_an_Toi_uu_Random_Forest_Le_Quyet_Tien_2026-11-27_GitHub_Public.docx)
có nhãn **Kho mã nguồn GitHub công khai (Public)** và URL đầy đủ bấm được
ngay trang thông tin sinh viên (trang thứ 3 của file). Link trong phụ lục
và tài liệu tham khảo vẫn giữ nguyên. Source builder cũng được cập nhật
để các lần dựng sau có phần liên kết này.

Chỉ thêm hai đoạn và một quan hệ hyperlink vào bản sao báo cáo; bản Word
trước đó và toàn bộ nội dung/số liệu/hình/styles được giữ nguyên.
Bản mới vẫn 34 trang, mục lục không đổi số trang. Kiểm tra cấu trúc, hyperlink,
các file cũ và bố cục bằng Word/PNG được ghi trong
[bằng chứng kiểm tra](github-public-validation-2026-11-27.json).

Các trang tìm tài liệu được trỏ sang bản mới. Gói nộp có hậu tố
`GITHUB_PUBLIC` được tạo từ commit sạch và có file SHA256 đi kèm;
không ghi đè gói nộp trước đó. Chưa xác nhận cô duyệt hoặc sinh viên nộp LMS.
